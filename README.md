# Power Station Controller (WB-MRWM2)

Веб-интерфейс и сервис управления зарядной станцией, оптимизированный под сенсорные экраны 1024×600 (режим киоска).
Система управляет двухканальным релейным модулем с измерением мощности **Wiren Board WB-MRWM2** по протоколу **Modbus RTU (RS-485)**.

## Возможности

- **Интерфейс зарядки**:
  - Выбор времени зарядки пресетами (20, 40, 60 мин, до полной зарядки) или ввод своего времени на экранном Numpad.
  - Анимированная физическая модель уровня жидкости на HTML5 Canvas с волнами и брызгами.
  - Отображение текущей потребляемой мощности по каждому каналу в реальном времени.
  - Виджет контроля замка / геркона (сухой контакт на входе 1 модуля).
  - История завершенных сессий с сохранением в `history.json`.
- **Инженерные настройки (защищены PIN-кодом `1234`)**:
  - Раздельное переключение реле каналов 1 и 2 с кулдауном 3 секунды для защиты от дребезга команд.
  - Мониторинг связи Modbus, активной мощности и статуса геркона.
- **Отказоустойчивость**:
  - Режим симуляции при отсутствии физического подключения к `/dev/ttyUSB0` (позволяет тестировать интерфейс на любом ПК).

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Dr0b0t1488/power_stashion.git
   cd power_stashion
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:
   ```bash
   python app.py
   ```
   Сервер запустится на `http://0.0.0.0:5000/`.
